# Plantilla React simple

Esta estructura es para crear sitios React estáticos sin necesidad de bundler.

## Archivos

- `index.html` - Página principal que carga React, ReactDOM y Babel.
- `app.jsx` - Código React con JSX.
- `styles.css` - Estilos básicos.

## Cómo usar

1. Copia la carpeta `react-template` y cambia el nombre.
2. Edita `app.jsx` con tu contenido.
3. Abre `index.html` en el navegador para ver tu sitio.

## Publicar en internet

### GitHub Pages
1. Sube la carpeta a un repositorio en GitHub.
2. Ve a `Settings > Pages` y elige la rama `main` y la carpeta `/root`.
3. Guarda y espera la URL.

### Netlify
1. Crea cuenta en netlify.com.
2. Arrastra la carpeta con `index.html` a Netlify Drop.
3. Netlify te dará una URL para tu sitio.

### Vercel
1. Crea cuenta en vercel.com.
2. Importa tu repositorio o sube los archivos.
3. Vercel construye y publica el sitio.

## Nota
Este sitio funciona en Chrome y cualquier navegador moderno si abres `index.html`.
